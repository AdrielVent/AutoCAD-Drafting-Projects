# Slotted Guide Plate (AutoCAD 2026)

### Project Overview
This is a precision drafting exercise focused on mastering standard 2D drawing techniques and layer management in AutoCAD 2026. The goal was to create a fully defined mechanical part using orthographic projection.

### 🛠️ Technical Skills Applied
* **Software:** Autodesk AutoCAD 2026
* **Standards:** ASME Y14.5 (Dimensioning & Tolerancing)
* **Layer Management:** Strict separation of Object, Center, Hidden, and Dimension lines.
* **Drafting Techniques:**
    * Orthographic Projection (Top and Front Views)
    * Precision Coordinates & Object Snaps
    * Fillets & Circular Geometry
